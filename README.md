# Эволюция — правила игры

Мобильная веб-страница с правилами настольной игры «Эволюция»: подготовка, фазы развития и выживания, действия, хищники, таблица свойств и подсчёт очков.

Сайт статический и разворачивается на Cloudflare Workers (static assets): серверного кода нет, Cloudflare раздаёт файлы из `public/`.

## Структура

```
public/
  index.html    страница правил
  app.js        интерактив: бросок кубиков, таблица свойств, подсчёт очков
  img/          картинки свойств (256×256)
  favicon.svg
  404.html
wrangler.jsonc  конфиг Worker
```

## Деплой

Worker подключён к репозиторию через Workers Builds: каждый пуш в рабочую ветку запускает `npx wrangler deploy`.

- Поле `name` в `wrangler.jsonc` должно совпадать с именем Worker в панели Cloudflare. Если не совпадает, сборка падает.
- Сборочная команда не нужна. Команда деплоя: `npx wrangler deploy`.
- Ключи и переменные окружения не нужны.

## Локальный просмотр

```
npx wrangler dev
```

Или любой статический сервер из папки `public/`.
